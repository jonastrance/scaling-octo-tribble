# Scaling Octo-Tribble

A revolutionary WebGL experience featuring a living, growing digital creature inspired by the legendary Star Trek tribbles, with an autumn October theme.

## About

This is a unique, interactive web experience that showcases a "scaling October tribble" - a 3D animated creature that continuously grows, shrinks, and responds to user interaction. The tribble is rendered using WebGL and Three.js, featuring:

- **Dynamic Scaling Animation**: Watch the tribble grow and shrink organically
- **October/Autumn Theme**: Warm autumn colors (oranges, browns, reds) dance across the creature
- **Particle Fur System**: 2000+ particles create a fuzzy, tribble-like appearance
- **Interactive Motion**: The tribble follows your mouse cursor
- **Pulsating Life**: Realistic breathing and movement patterns
- **Revolutionary Design**: A completely unique visual experience

## Features

- **WebGL/Three.js 3D Graphics**: Hardware-accelerated 3D rendering
- **Real-time Animation**: Smooth 60 FPS animations
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Interactive Elements**: Mouse tracking for creature interaction
- **Autumn Color Palette**: Carefully selected October-themed colors
- **Particle System**: Advanced fur simulation with 2000+ particles
- **Dynamic Lighting**: Multiple light sources for depth and atmosphere

## Viewing the Website

Simply open `index.html` in a modern web browser that supports WebGL:

```bash
# Option 1: Open directly
open index.html

# Option 2: Serve with Python
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your browser.

### Requirements

- Modern web browser with WebGL support (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Hardware acceleration enabled for best performance

## The Concept

The "Scaling Octo-Tribble" represents:
- **Scaling**: The creature continuously grows and shrinks, representing digital scalability
- **Octo**: References GitHub's octopus mascot, merging with the tribble concept
- **Tribble**: Inspired by Star Trek's fuzzy, reproducing creatures
- **October**: Autumn theme with warm, seasonal colors
