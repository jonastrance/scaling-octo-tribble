# MK Property Services LLC

Professional property management website serving Northern Neck, Virginia.

## About

This website represents MK Property Services LLC, a comprehensive property management company specializing in maintenance, cleaning, decoration, and multi-faceted services for homeowners and renters in the Northern Neck region of Virginia.

## Services

- Property Maintenance
- Professional Cleaning
- Decoration Services
- Property Management
- Home Repairs
- Multi-Faceted Services

## Viewing the Website

Open `index.html` in your web browser to view the website locally, or serve it using any web server:

```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080` in your browser.

## Features

- Responsive design for mobile and desktop
- Professional styling with modern CSS
- Easy-to-navigate sections (Home, About, Services, Contact)
- Contact form for quote requests
